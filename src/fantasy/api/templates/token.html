Opción avanzada: pegar el token a mano

Solo si lo anterior no funciona. El token caduca cada día, así que tendrás que repetirlo.

  1. Entra en laligafantasy.com y haz login normalmente.
  2. Abre las herramientas de desarrollador de tu navegador (F12, o clic derecho → Inspeccionar) y ve a la pestaña Red / Network.
  3. Recarga la página y busca cualquier petición hacia la API de LaLiga Fantasy.
  4. En la pestaña de cabeceras de esa petición, localiza Authorization: Bearer <token>.
  5. Copia solo el valor del token (sin la palabra "Bearer") y pégalo abajo.
